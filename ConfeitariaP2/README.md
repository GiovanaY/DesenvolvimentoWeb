# Confeitaria P1 — frontend integrado com backend

Este pacote contém o frontend Angular da Confeitaria P1 e o backend Java/Spring Boot usado como base (lojinha).

- `frontend/`: aplicação Angular original com serviços HTTP de produto, cliente e pedido.
- `backend/`: backend Spring Boot da referência.

Leia `frontend/README-INTEGRACAO.md` para as instruções de execução e os endpoints usados.


## Subir para GitHub
Crie um repositório novo no GitHub e, no terminal aberto na raiz deste diretório, execute:


```bash
git init
git add .
git commit -m "Integra frontend Confeitaria com API Spring Boot"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/ConfeitariaIntegrada.git
git push -u origin main
```
Troque `SEU-USUARIO` pelo seu nome de usuário e use a URL que o GitHub fornecer ao criar o repositório.
